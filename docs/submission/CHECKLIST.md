# Submission checklist

**Deadline: 7 Nov 2026, 23:59 IST (aim for 23:00).** Official rules: https://www.wemakedevs.org/hackathons/switch/rules. Overview: https://www.wemakedevs.org/hackathons/switch.

## From the official rules
- **Judging criteria:** Use of Switch ("Is Switch central, and would the project stop working without it?"); Technical execution ("Does it run, and could someone clone the repo and reproduce it?"); Creativity and impact ("Is it a fresh idea that solves a problem a real team has?"); Presentation ("Do the demo video and README make clear how Switch is used?").
- **Required items:** demo video and README. The pages list no form fields or video length, so check the form itself.
- **Existing work:** "Existing agents, libraries and templates are fine. The Switch setup and the workflow your agents run need to be built during the hackathon." "Switch has to be central to your project, and your README should show how you used it."
- **AI tools:** allowed. "You should understand what you submit and be able to explain how it works."
- **Prizes to aim for:** Track 01, Best Business Workflow ($2,000). Optional: Best Blog side track.
